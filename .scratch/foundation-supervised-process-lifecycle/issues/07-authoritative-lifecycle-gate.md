# 07 — 权威门禁纳入完整进程生命周期并拒绝测试污染

Type: evidence
Status: ready-for-agent
Blocked by: 04 — Application 与 Management 意外停止被监督为关键失败; 05 — 真实子进程证明信号类别、日志时间线和退出码; 06 — 生产 Compose 在 grace period 内完成正常停止

**What to build:** 将 Application排空、Runtime正常与失败结果、关键 Listener监督、真实子进程信号和生产 Compose停止证据纳入唯一权威 `task check`，并继续拒绝任何为生命周期测试加入生产镜像的 Handler、控制、夹具或依赖。

## Acceptance criteria

- [ ] `task check` 串联本前沿全部必要的Go行为、真实子进程和生产 Compose生命周期门禁。
- [ ] 任一新增生命周期子门禁非零时，权威门禁停止并原样传播非零结果。
- [ ] 权威门禁合同测试同步声明新增步骤的完整顺序和失败传播。
- [ ] CI仍然只调用与本地相同的 `task check`，不维护第二套生命周期命令清单。
- [ ] 生产镜像检查继续拒绝测试 Handler、测试命令、故障控制、E2E源码、Playwright和浏览器依赖。
- [ ] 独立污染夹具能够证明生产产物检查器会拒绝生命周期测试控制。
- [ ] 完整门禁成功输出包含本前沿真实进程和生产 Compose证据，而不只包含单元测试绿色结果。

## 它让系统向前移动什么

当前退出前沿获得一个稳定、可重复、可用于本地和CI交接的完成定义，同时证明更强的生命周期验收没有污染正式生产产物。

## 当前事实和调用链

现有权威门禁按固定顺序运行格式、门禁自检、Go、OpenAPI、Web、真实PostgreSQL集成、生产启动、Playwright、数据库生命周期和生产产物检查，并在CI中由同一根命令调用。

前序Ticket会新增HTTP排空、Runtime失败、真实信号和生产Compose停止入口。本Ticket只负责把这些已独立可运行的证据纳入权威完成定义，并同步门禁自身的合同测试和生产纯净性检查。

本Ticket建立：

```text
task check
→ 现有全部门禁
→ HTTP/Runtime生命周期行为
→ 真实子进程信号和退出码
→ 正式生产Compose停止
→ 生产镜像与污染夹具检查
→ 汇总成功或传播第一个非零结果
```

## 唯一主要结果

`task check`成为受监督生产进程退出前沿的唯一完整验收入口，并拒绝因生命周期测试引入的任何生产污染。

## 输入和前置状态

- Ticket 04的关键Listener失败行为；
- Ticket 05的真实子进程信号和退出码证据；
- Ticket 06的生产Compose停止证据；
- 现有权威门禁运行器、合同夹具和生产产物检查器；
- CI中现有的单一根命令入口。

## 业务规则或待决问题

- 每个生命周期行为必须先有独立可运行入口，权威门禁只负责组合和传播。
- 任一子门禁失败时整体立即非零，不能继续后伪造综合成功。
- 门禁合同夹具必须独立于真正Docker验收，稳定证明步骤顺序和失败传播。
- 生产纯净性检查不能只依赖真实镜像恰好干净，必须有污染夹具证明拒绝能力。
- 绿色 `task check`是当前前沿必要证据，但仍需保留真实进程、请求、健康和Compose时间线输出。

## 成功后的状态变化

本地开发者和CI使用同一个命令即可取得当前前沿全部行为与生产证据；任一生命周期回归会使整体门禁失败。

## 失败或拒绝行为

使用独立门禁夹具让新增生命周期步骤故意非零，并使用独立生产产物夹具加入测试 Handler或故障控制。权威门禁和产物检查器必须分别拒绝这些结果。

## 预计修改范围

- 根权威门禁步骤清单；
- 门禁合同测试和独立Task夹具；
- 生命周期测试Task入口；
- 生产产物分类与污染夹具；
- CI入口的一致性检查；
- 当前前沿验收说明。

## 自动测试

1. 权威门禁合同按准确顺序执行全部现有和新增步骤。
2. 新增生命周期步骤故意失败时，整体门禁停止并传播非零结果。
3. 含生命周期测试 Handler、命令或控制的污染夹具被生产产物检查器拒绝。

## 运行演示

在满足现有工具前置条件的环境运行一次完整 `task check`，展示HTTP排空、Runtime失败、真实信号、生产Compose停止、门禁自检和生产镜像纯净性结果。

## 明确不做

- 后续前沿测试；
- Release Bundle、签名、SBOM或漏洞扫描；
- 正式发布流水线；
- 以门禁汇总替代真实运行时间线；
- 生产测试控制或专用镜像。

## 完成证据

- 完整 `task check`输出和最终零结果；
- 门禁步骤顺序及失败传播合同；
- 本前沿真实子进程和生产Compose证据；
- 生产镜像文件与依赖检查；
- 生命周期污染夹具被拒绝的结果；
- CI继续调用同一根命令的配置。

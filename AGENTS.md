## Agent skills

### Issue tracker

Issues and specs are tracked as local Markdown files under `.scratch/`. See `docs/agents/issue-tracker.md`.

### Triage labels

The tracker uses the five default canonical triage labels. See `docs/agents/triage-labels.md`.

### Domain docs

This is a single-context repository with domain context at `CONTEXT.md` and decisions under `docs/adr/`, when present. See `docs/agents/domain.md`.
